## Purpose

定义 File Cooker 的 AI 属性补全能力：AI 按笔记内容批量推断 frontmatter 属性（tags / aliases / 自定义属性）并生成提案，用户在确认窗中审核、修改后批量应用，全程复用既有"提案-确认"安全模型与备份回滚通道。该能力默认关闭（opt-in），并建立后续 AI 功能共用的服务配置与分批调度行为契约。

## ADDED Requirements

### Requirement: AI 服务配置与可用性检查

系统 MUST 提供独立的 AI 设置分区，包含总开关（默认关闭）、OpenAI 兼容服务地址、模型名、API Key、分批与截断参数、推断项开关（tags / aliases / 自定义属性列表）与标签语言选项。API Key MUST 优先存储于 Obsidian SecretStorage，设置文件中的明文仅作为回退并在设置页标注风险。

#### Scenario: AI 未启用时命令被阻断

- **GIVEN** AI 设置总开关为关闭，或服务地址 / API Key 未配置
- **WHEN** 用户执行任一 AI 属性补全命令
- **THEN** 系统 MUST 给出可理解提示并终止，MUST NOT 发起任何网络请求，MUST NOT 打开任何弹窗

#### Scenario: 配置完整时进入推断流程

- **GIVEN** AI 设置已启用且配置完整
- **WHEN** 用户执行任一 AI 属性补全命令
- **THEN** 系统 MUST 进入推断流程并展示进度反馈

#### Scenario: API Key 不默认落明文

- **GIVEN** 用户在设置页保存 API Key 且 SecretStorage 可用
- **WHEN** 设置数据被持久化
- **THEN** API Key MUST 存储于 SecretStorage，设置文件中不保留该明文

### Requirement: 多来源入口挂接

系统 MUST 在既有全部文件来源（剪贴板 / 当前文件链接 / 搜索结果 / Dataview 查询 / Bases 查询）各提供至少一个 AI 属性补全命令，并 MUST 在文件管理器右键菜单提供单文件 AI 属性补全入口。各入口产出的文件集合行为与对应来源的既有命令保持一致（含批量上限与无来源时的阻断提示）。

#### Scenario: 从任一来源触发

- **GIVEN** 用户在某来源上下文中（如 Bases 查询结果可访问）
- **WHEN** 用户执行该来源的 AI 属性补全命令
- **THEN** 系统 MUST 以该来源的文件集合作为推断输入并进入推断流程

#### Scenario: 来源为空时阻断

- **GIVEN** 当前来源无法产出任何文件（如剪贴板无文件链接）
- **WHEN** 用户执行 AI 属性补全命令
- **THEN** 系统 MUST 给出与该来源既有命令一致的可理解提示，MUST NOT 进入推断流程

#### Scenario: 批量上限生效

- **GIVEN** 来源产出的文件数超过设置中的批量上限
- **WHEN** 系统构建推断输入
- **THEN** 系统 MUST 按上限截断，行为与既有来源命令一致

### Requirement: 按内容批量推断并生成提案

系统 MUST 将每篇笔记的标题与截断后的正文内容（截断长度可配置）随结构化指令发送给 AI 服务，MUST 同时注入全库标签词表（有上限）引导模型优先复用既有标签体系，并 MUST 对响应执行校验：JSON 解析、按路径回配文件（无法回配的条目丢弃并计数）、值规范化（tags 转小写、去 `#`、去空白、去重）。推断过程中用户 MUST 能取消，取消后未发出的批次不再发出。

#### Scenario: 推断成功产出提案

- **GIVEN** 用户从任一来源触发 AI 属性补全且网络正常
- **WHEN** 全部批次推断完成
- **THEN** 系统 MUST 展示逐文件提案列表，每条包含文件路径与各属性的提案值

#### Scenario: 响应含无法回配的条目

- **GIVEN** AI 返回的某条结果路径无法匹配到输入文件
- **WHEN** 系统校验响应
- **THEN** 系统 MUST 丢弃该条目且不影响其余提案的生成

#### Scenario: 推断中取消

- **GIVEN** 推断正在进行且部分批次已完成
- **WHEN** 用户在进度反馈中执行取消
- **THEN** 系统 MUST 停止发出剩余批次，已完成部分 MUST NOT 写入任何文件

### Requirement: 提案审核与确认

系统 MUST 以确认弹窗展示提案，支持逐条勾选（默认全选）与提案值编辑；弹窗 MUST 明示将发送给 AI 服务的内容范围（文件名与正文前 N 字符）。用户确认前系统 MUST NOT 写入任何文件；取消 MUST 零写入。

#### Scenario: 审核后部分应用

- **GIVEN** 提案列表包含多个文件的提案且部分被取消勾选
- **WHEN** 用户点击应用
- **THEN** 系统 MUST 仅对勾选条目执行写入，未勾选文件保持原样

#### Scenario: 全部取消勾选后应用

- **GIVEN** 用户取消全部提案勾选
- **WHEN** 用户点击应用
- **THEN** 系统 MUST 不执行任何写入并正常关闭弹窗

#### Scenario: 提案与现有值相同

- **GIVEN** 某文件的某属性提案值与现有值完全相同
- **WHEN** 系统生成提案列表
- **THEN** 系统 MUST 跳过该条目，不产生无意义写入

#### Scenario: 编辑提案值

- **GIVEN** 提案列表中某条提案值不符合用户预期
- **WHEN** 用户直接编辑该提案值后应用
- **THEN** 系统 MUST 按编辑后的值写入

### Requirement: 应用提案的写入语义

系统 MUST 通过结构化 frontmatter 读写接口应用提案：tags / aliases / cssclasses 等多值属性 MUST 追加合入现有值（去重），不覆盖；自定义标量属性默认仅在该属性不存在时写入，设置面板 MUST 提供覆盖开关。应用前 MUST 为涉及文件创建备份快照，应用成功后记录可回滚；应用失败 MUST 上报且不中断其余文件。

#### Scenario: 多值属性追加合入

- **GIVEN** 某文件现有 tags 为 `["a"]`，提案值为 `["b", "a"]`
- **WHEN** 用户应用该提案
- **THEN** 文件 tags MUST 变为 `["a", "b"]`，顺序与去重由系统保证，现有值不丢失

#### Scenario: 标量属性默认不覆盖

- **GIVEN** 某文件已存在自定义标量属性 `status: done`，提案值为 `doing`，覆盖开关关闭
- **WHEN** 用户应用该提案
- **THEN** 系统 MUST 保留 `done` 不写入，或以可感知方式提示该条目被跳过

#### Scenario: 应用前创建备份

- **GIVEN** 备份功能开启且用户确认应用若干提案
- **WHEN** 系统执行写入
- **THEN** 系统 MUST 在写入前为涉及文件创建备份快照，完成后可在备份历史中回滚本次批量操作

#### Scenario: 单文件写入失败不拖垮整批

- **GIVEN** 批量应用中某文件写入抛出异常
- **WHEN** 系统处理该异常
- **THEN** 系统 MUST 上报该文件失败原因，继续处理其余文件，并在完成提示中汇报成功 / 跳过 / 失败数量

### Requirement: 推断失败的可感知处理

网络失败、HTTP 错误、响应解析失败 MUST 以可理解提示上报。单批失败 MUST 有限次重试，重试仍失败则仅标记该批文件失败，MUST NOT 中断整体推断；全部批次失败时 MUST 明确告知且零写入。失败文件的路径 MUST 对用户可见。

#### Scenario: 单批失败重试后恢复

- **GIVEN** 某批次请求因网络抖动失败且未超过重试上限
- **WHEN** 系统重试该批次
- **THEN** 重试成功后该批文件 MUST 正常进入提案列表

#### Scenario: 单批重试仍失败

- **GIVEN** 某批次重试后仍失败
- **WHEN** 整体推断完成
- **THEN** 其余批次 MUST 正常产出提案，失败批次的文件路径 MUST 在完成提示中可见

#### Scenario: 全部批次失败

- **GIVEN** 所有批次均推断失败
- **WHEN** 系统结束流程
- **THEN** 系统 MUST 明确告知失败，MUST NOT 打开提案弹窗，MUST NOT 写入任何文件

### Requirement: 隐私与出域控制

系统 MUST 在发送任何笔记内容前于确认界面明示发送范围；发送内容长度 MUST 受可配置的截断参数约束。AI 能力总开关 MUST 默认关闭，用户不主动启用则任何命令不得产生网络请求。

#### Scenario: 发送范围明示

- **GIVEN** 推断完成进入提案弹窗
- **WHEN** 用户查看弹窗说明区
- **THEN** 弹窗 MUST 展示"每篇笔记发送文件名与正文前 N 字符"一类明示信息，N 为当前配置值

#### Scenario: 默认关闭不出域

- **GIVEN** 用户从未启用 AI 设置
- **WHEN** 用户执行任意 File Cooker 命令（含 AI 命令）
- **THEN** 系统 MUST NOT 发起任何 AI 服务网络请求
